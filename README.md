# Human · Rill 通讯录 0.1.0

提供通讯录列表、姓名/电话/公司搜索、分组、星标、联系人详情、创建编辑、归档、头像与平滑动画。支持深色模式、桌面和手机布局。

## 通过 Git 安装

在 Rill 插件管理添加 GitHub 仓库 `jzbjing-pixel/human`，选择 Git 仓库安装，资源名为 `rill-plugin.git.zip`。发布者公钥取本仓库 `publisher.json` 的 `publicKey`。插件包路径为 `dist/rill-plugin.git.zip`，内含清单、P-256 签名及压缩运行文件，宿主安装前校验签名和文件哈希。

需要新版 Rill：公共 Host API 2、外部插件运行及新增 `system.dial` 能力。旧版未包含 system.dial 时会拒绝安装；请先升级支持该能力的宿主。本次已完成宿主源码适配，不包含新宿主 APK。

## 使用

打开通讯录，点击“关联多维表”。可以新建通讯录表，或选择已有的表/视图。已有表需具备宿主管理的 JSON 记录来源；无写入目标时需明确勾选启用。可映射姓名、电话、邮箱、公司、职位、分组、备注字段，插件只读取授权范围内的数据。

每页 100 条，点击加载更多。搜索和分组针对已加载记录。头像支持 2 MiB 内 PNG/JPEG/WebP，通过记录附件保存，缺省显示姓名头像。归档保留原件，可在多维表将 archived 改为 false 恢复。

手机详情点击“拨打电话”，宿主校验联系人权限后打开 Android 拨号器并填入号码，由用户点击拨出；无需 CALL_PHONE 权限。不支持 USSD 和分机指令。桌面及浏览器提示平台不支持。

联系人和设置保存在 Rill 多维表中，卸载不删除联系人。不支持飞书同步和手机系统通讯录导入。模拟浏览器桌面/390px/320px 及宿主 API 测试通过；Android 真机安装和拨号待验收。

此仓库仅发布可安装签名版本及安装说明，开发源码不公开。
